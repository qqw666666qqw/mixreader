# 夹读 JiaduReader

**把中文书里的中文词替换成任意目标语词条，在熟悉的语境里学外语。**

上传一本目标语词书和一本中文书，夹读会自动把书中出现过的中文词替换成词书左侧的英语、日语、韩语、法语等词条：

> 他养了一只 **dog（狗）**，每天带它去 **river（河）** 边 **walk（散步）**。

纯前端实现，所有解析和替换都在浏览器本地完成，**不上传任何文件、不依赖后端、不调用大模型**。

👉 <https://qqw666666qqw.github.io/mixreader/> （GitHub Pages）

打开后点「载入示例」即可体验，无需准备文件。

薄荷绿 / 粉红配色版本：<https://qqw666666qqw.github.io/mixreader/mint/>。原网址保持米色 / 砖红配色，两版共用导入和阅读功能，均免费、无需登录。导出的阅读包目前仍使用原版米色配色。

在较新的 Safari、Chrome、Edge 或 Firefox 中使用。电脑、Android 手机、iPhone 和 iPad 都可以通过文件选择器导入各自设备上的词书和中文书；iPhone/iPad 可从“文件”或 iCloud Drive 选择。微信等应用的内置浏览器如无法选文件，请在系统浏览器打开。

导入文件在当前浏览器处理，并通过 IndexedDB 自动保存解析文本、词书和阅读进度，不会上传到 GitHub，也不会跨设备同步。再次进入同一浏览器会恢复章节和章内文字位置；米色和薄荷粉两版共用本机书库。手机处理超大 PDF/DOCX 时可能受内存限制，扫描图片 PDF 暂不支持 OCR。

在页面的“本机书库与进度”中可以继续阅读、删除中文书、备份和恢复。Excel 保存各工作表的文本单元格以及选列信息；不保留原文件格式或宏。原 PDF/DOCX 文件不保存，保存的是已提取的文本。清理网站数据、无痕模式或浏览器回收空间可能丢失书库；“申请持久保存”由浏览器决定是否批准，不能保证永久保存。备份文件内含私人书籍正文，请妥善保存。不同书籍按内容哈希区分，即使同名也保留独立进度。

书库列表显示字数、保存时间和记录标识，方便区分同名文件的不同内容（包括乱码版本）。删除仅移除选中的中文书和进度，不删除原文件或词书；与自动保存串行处理，并保留不含正文的删除标记，避免旧页面自动保存把书写回。支持的浏览器会同步通知同源的其他夹读页面更新列表。主动重新导入原文件或确认恢复备份可恢复被删除的内容。存储结构升级时请刷新已打开的旧页面。

单词旁“发音”按钮支持设备语音和英文联网发音，播放状态在手机屏幕底部显示。鸿蒙等浏览器缺少系统语音时，在“单词发音”中选择“英文联网发音”并勾选允许，或点底部“同意联网并发音”。默认不请求第三方；同意后仅发送点击的词条给有道公开词典音频服务，不发送书籍正文。联网发音需网络且仅支持英文英音/美音，使用标准音频播放，不依赖 Web Speech API；第三方服务没有可用性保证，可能限流、停用或无对应读音。可随时取消允许。自动模式在未检测到对应设备声音或系统发音失败后，下次点击优先使用已允许的英文联网发音；失败后重试需再次点击，避免手机自动播放限制。

其他语种仍使用浏览器 Web Speech API，可选语言、口音、设备声音及语速；点单词显示释义的行为保留，也可开启点词条同时发音。可用声音取决于设备，部分声音需要联网，词条可能由系统语音服务处理；不能保证多音词的语境读音。两种方式都不会上传整本词书或正文。导出的离线阅读包目前不包含这些新增本机书库和发音控件。

## 免费部署

GitHub Pages 从 `main` 分支根目录发布，地址为上述在线体验链接。后续推送到 `main` 的代码会自动重新部署，不需要本机保持开机。`.nojekyll` 用于直接发布静态文件。

发布仓库中仅包含网页代码和自带示例；不要把私人书籍加入公开仓库。

修改原版 `index.html` 的控件或资源后，运行 `node scripts/build-mint.js` 同步生成薄荷粉页面，再运行 `node scripts/build-mint.js --check` 检查。`mint/theme.css` 只覆盖第二版的配色，不影响原版。

## 功能特性

- **多格式支持**：词书与中文书均支持 `.txt`（UTF-8/GBK）、`.docx`、`.pdf`；词书额外支持 Excel `.xlsx` / `.xls`
- **本机书库**：自动保存书籍、词书、Excel 选列、设置和章节内阅读位置，提供备份 / 恢复
- **单词发音**：设备语音及经同意开启的英文联网音频，兼容缺少系统语音的浏览器，支持口音和语速；手机可见播放提示
- **多语种词书**：支持拉丁字母、日语、韩语、俄语、阿拉伯语等书写系统
- **保守词书清洗**：自动过滤页眉页脚等版式噪声、高风险单字和多义冲突，并提供清洗报告
- **自测模式**：中文注释默认模糊隐藏，点击单词才显示，先回忆再核对；支持「全部显示 / 全部隐藏」
- **三种显示模式**：`目标语（中文）` / 纯目标语 / `中文（目标语）`
- **长书分章阅读**：自动识别章节标题，百万字文本按章加载；无标题时自动分页
- **替换密度调节**：故意留空一部分词不替换，考查自己
- **最短词长过滤**：避免单字词切坏固定搭配
- **一键导出**：生成混读版 TXT，或导出可传到手机/iPad 的离线 HTML 阅读包
- **本篇重点词统计**：自动汇总被替换的单词及出现次数

## 工作原理

不使用大模型，核心是纯规则匹配（见 `core.js`）：

1. 解析词书，提取「中文释义 → 目标语词条」映射（自动处理词性标注、音标、多义项、去掉「的」的词干）
2. 对中文正文做**正向最长匹配**扫描，命中词条即替换

优点：免费、离线、毫秒级处理几十万字。
默认采用保守策略：最短替换词长为 2，同一个中文释义对应多个目标语词条时不自动替换。这样能避免把「在职」中的「在」替换成 `aboard` 一类错误。关闭“严格清洗”后会恢复宽松解析，但误替换风险更高。

局限：规则匹配无法理解完整语境，因此不能保证所有一词多义都选择正确。遇到要求很高的语境消歧，需要接入分词或上下文模型。

## 词书格式

每行一个词条，左侧是目标语，右侧必须包含中文释义。格式宽松：

```
apple 苹果
ice cream 冰淇淋
bonjour interj. 你好
überraschen 使惊讶
こんにちは 你好
食べる [たべる] 吃；食用
사랑 爱
привет 你好
مرحبا 你好
```

## Excel 词书

每行一个词条，单词与中文释义放在不同列，例如 A 列 `apple`、B 列 `苹果`。上传后可选择工作表、单词列和中文释义列；带 `单词 / 中文释义`、`word / meaning` 等常见表头时会自动选列并跳过表头。没有表头时按内容建议列，请核对选择。

只读取所选两列，其他列的音标、例句、序号等不会参与替换。空白或没有中文释义的行会跳过；只有英文单词的表格需要先补充中文释义。多工作表只使用当前选中的表，不会混合导入。保留原有词书清洗与歧义过滤，公式只读取文件中已保存的结果，不运行公式或宏；加密文件请先解除密码。

Excel 解析库随网站提供，不依赖第三方 CDN；文件不会离开浏览器。超大表格仍受设备内存限制。

## 本地运行

```bash
git clone https://github.com/qqw666666qqw/mixreader.git
cd mixreader
open index.html   # 直接双击打开也可以
```

> 解析 docx/pdf 依赖 CDN 加载 [mammoth](https://github.com/mwilliamson/mammoth.js) 与 [pdf.js](https://github.com/mozilla/pdf.js)，需联网；纯 txt 完全离线可用。

## 目录结构

```
├── index.html    # 界面与样式
├── core.js       # 词书解析 + 替换引擎（纯函数，可移植到小程序/后端）
├── app.js        # 交互与文件读取（txt/docx/pdf）
├── excel.js      # Excel 词书选列与行转换
├── vendor/       # SheetJS 0.20.3 浏览器解析库及 Apache-2.0 许可证
└── samples/      # 示例词书与示例中文书（txt/docx/pdf 三种格式）
```
